# Chez Sarah – Online Dessert Shop

## Project Description

Chez Sarah is a React-based online dessert shop website that allows users to browse different dessert categories, add items to a shopping cart, and complete a checkout process. The website is fully responsive and works on both desktop and mobile devices.

## Technologies Used

- React.js
- JavaScript (ES6)
- React Router DOM
- CSS3
- Git & GitHub
- Netlify

## System Features

- Multi-page navigation using React Router
- Dessert categories: Cakes, Crepe, Hot Drinks, Cold Drinks
- Add to Cart functionality
- Remove items from cart
- Dynamic cart total calculation
- Checkout page
- Responsive design for mobile and desktop

## Project Setup

1. Clone the repository:
git clone https://github.com/sarrrrrah05/chez-sarah.git

2. Install dependencies:
npm install

3. Start the project:
npm start

4. Open:
http://localhost:3000
